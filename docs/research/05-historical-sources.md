# Historical custom-Ocarina song communities

The music research began as an attempt to recover late-1990s and early-2000s custom song tabs and translate them to modern controls. This predates the MIDI of Time application and deserves a place in the same reference site, separately attributed.

## Notation translation warning

Original N64 controls use `A`, C arrows and `Z` / `R` modifiers. In the modern remake's *Classic* 8BitDo layout the physical RB is a normal D pitch, not the N64 `R` sharp modifier. Translate **musical notes**, not strings of matching button names. The Xbox labels, Nintendo on-screen names, and debug-HID names are different.

Historical `Animal Crossing` town tunes for Blink-182 (`Adam's Song` and others) are not evidence of playable OoT tabs. The November 9 dossier explicitly distinguished those game formats and flagged several purported OoT Blink-182 tabs from a secondary report as unverified. Similarly, *James Bond Theme* and *GoldenEye 007* game soundtrack arrangements must not be silently conflated.

## Suggested community contributions

The repository can welcome new arrangements with original author attribution, controller layout, exact note sequence, whether player-tested, and a link to a performance demonstration. Label anything not personally tested as 'unverified' or 'adaptation candidate'.
