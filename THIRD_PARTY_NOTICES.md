# Third-party components

MIDI of Time's own code is MIT-licensed (see LICENSE). It has **no third-party Python packages at runtime**; it uses only the Python standard library and tkinter.

The portable Windows build bundles the components below. Their licenses permit redistribution.

| Component | Version | Used for | License |
|---|---|---|---|
| CPython runtime and standard library | 3.15.2 (python.org build) | Runs the program | Python Software Foundation License v2 (permissive) — https://docs.python.org/3/license.html |
| Tcl/Tk (via tkinter) | 9.0 | The window and controls | Tcl/Tk license (BSD-style) — https://www.tcl.tk/software/tcltk/license.html |
| PyInstaller bootloader | 6.22.3 | Starts the bundled app (`MIDI of Time.exe`) | GPL-2.0 **with a bootloader exception** that explicitly allows distributing bundled programs under any license — https://pyinstaller.org/en/stable/license.html |
| Other runtime libraries bundled by Python's Windows build | see `_internal\` | Standard-library internals (for example zlib, libffi, OpenSSL, if present) | Permissive licenses (zlib, MIT, Apache-2.0); see the Python license page above |

The exact list of bundled files is in `INVENTORY.txt`.

**Not included:** any Nintendo software or assets, any emulator files, or any MIDI collections. The demo song is generated by MIDI of Time itself.

**Optional, not bundled:** [Everything](https://www.voidtools.com/) by voidtools speeds up MIDI folder search when you have it installed. MIDI of Time only calls its `es.exe` command-line tool.
